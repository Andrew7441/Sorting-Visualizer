# Linux Users
* Rename the folder to your game name
* CD into the build folder
* run `./premake5 gmake`
* CD back to the root
* run `make`
* you are good to go

# Run Project
* To run the project:
- build it first with 'make'
- run it with './bin/Debug/SortingVisualizer'

# Output files
The built code will be in the bin dir
